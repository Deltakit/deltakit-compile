# Installation

`deltakit-compile` supports Python 3.10 and later. Install it from PyPI with `pip`:

```bash
python -m pip install deltakit-compile
```

or with `uv`:

```bash
uv pip install deltakit-compile
```

`deltakit-compile` is also installed as a dependency of the
[`deltakit`](https://pypi.org/project/deltakit/) package.

To work on `deltakit-compile` itself, see
[Setup `deltakit` in development mode](https://deltakit-docs.riverlane.com/en/latest/CONTRIBUTING.html#setup-deltakit-in-development-mode).
