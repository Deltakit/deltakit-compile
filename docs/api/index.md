# API Reference

This reference is generated from the docstrings of `deltakit_compile`. Each public module,
class and function has its own page.

A class page lists the public methods and attributes the class defines, then those it inherits
from its `deltakit_compile` base classes. For classes built on [xDSL](https://xdsl.dev), it also
lists those inherited from the first xDSL base class, such as `IRDLOperation` or `ModulePass`.
Members xDSL defines further up, on `Operation` or `Attribute` for example, are documented in
the [xDSL API reference](https://docs.xdsl.dev/), which every base class name links to.

Operations and attributes also show their IRDL definition: their name, assembly format, traits
and fields.
